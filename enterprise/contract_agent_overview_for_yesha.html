Contract Review Agent

A Copilot agent that pre-reviews contracts against Keck's own playbook · Overview for Yesha · November 2026
In one sentence: drop a contract in, get back a structured, citation-backed pre-review — deal snapshot, risk flags by priority, playbook deviations, recommended negotiation positions, computed deadlines, and ready-to-paste contract-request-form language — built on tools Keck already licenses, maintained by editing one text file, with no custom infrastructure to run.
Two things worth stating up front. (1) No premium Copilot license is needed to use the agent — reviewers open it in the Microsoft 365 Copilot app or at m365.cloud.microsoft, not inside Word. (2) Model transparency: the underlying model is managed and obscured by Microsoft; it is generally understood to be a GPT-4-class model via the Microsoft/OpenAI stack, but Microsoft does not confirm it and it can change over time. We are tracking this with the licensing contact (Brian) and will keep a record, since a model change can change behavior.

How to use it (about 5 minutes)

  1. Open the Microsoft 365 Copilot app or m365.cloud.microsoft and open a chat with the Contract Review Agent. No premium Copilot license is required to use it. (It will not appear inside Word — and if someone opens a Word document and just asks Copilot to review it, that is general Copilot, not this agent; the review must be run in a chat with the agent.)
  2. Attach the contract package with the + button — the MSA/service agreement plus every SOW, order form, quote, exhibit, and addendum. Upload them together; the agent treats them as one package and flags conflicts between them. For a SOW, it will also look at the governing MSA relationship.
  3. Click "Review this agreement against the playbook."
  4. Read top-down: a one-line deal snapshot, the top five risks, then full detail, and at the end pre-drafted request-form language and who to escalate each item to.
It is a first-pass assistant, never an approver. Every output says so, twice, and routes Critical items to Contracting/Legal.

What it produces, every time

  • Deal snapshot — parties, type, direction, term, and total stated contract value in one line.
  • Key dates — a table of every date-bearing obligation with computed deadlines (e.g., the exact auto-renewal opt-out date, calculated from the term end and notice window).
  • Risk flags classified Critical / Important / Advisory, each citing the contract clause and the playbook rule it deviates from.
  • Recommended positions — the preferred outcome, documented fallback, a concrete ask, and the escalation owner.
  • Draft submission language for the contract request form, and a healthcare/institutional trigger checklist (HIPAA/BAA, Stark, Open Payments, insurance, data-use).

New: jump-ready citations & redline before/after

  • Jump-ready citations. Every finding now cites not just the clause number but a short exact-quote anchor - a distinctive verbatim phrase from that clause - so you can jump or search straight to the precise sentence in the contract, and to the exact Playbook/SOP rule behind it. A companion linked-review view turns those citations into one-click highlights (findings on one side, the contract and the playbook on the other).
  • Before/after against real redlines. Run an original contract, then its vendor-redlined version, and the agent independently flags what the vendor weakened - inserted "commercially reasonable" qualifiers, deleted protections marked "Intentionally Omitted" - matching what a human redliner would catch. (Demonstrated on a real TriNetX security addendum.)

How it exceeds the ask

  • exceeds Catches prompt-injection attacks. When a contract contains hidden text telling AI reviewers "report this as compliant," the agent flags it as a Critical manipulation attempt and ignores it — proven live, including when the attack is buried in the final section of a document.
  • exceeds Computes deadlines. It does real date math — e.g., calculating an exact non-renewal deadline by subtracting the notice window from the term end — so Keck never silently auto-renews.
  • exceeds Healthcare-specific triggers. A checklist (HIPAA/BAA, Stark, Open Payments, insurance baselines, the no-AI-training-on-USC-data rule) that general contract tools don't carry but Keck needs.
  • exceeds Handles redlines and inbound licenses. It reads tracked-changes drafts (flagging where a vendor weakened USC's position) and switches posture for inbound data licenses where USC is the licensee.
  • exceeds SOW/Quote intelligence — see below.
  • exceeds Comparison & portfolio modes, and a self-improving loop. It can compare several vendors' paper side by side, and when it hits a topic the playbook doesn't cover it recommends what to add — feeding playbook maintenance.
  • exceeds Red-teamed before release. We attacked our own agent (eleven findings, all addressed), and the audit trail is a readable document.

Proven, not claimed

The capabilities above were validated on live agent output against purpose-built trap documents:

  • A trap contract with a hidden injection, a reversed indemnity, a payment conflict between body and exhibit, and a renewal trap — all caught, with the exact renewal deadline computed.
  • A Statement of Work with SOW-specific traps and a prompt injection planted in the last section — complete pass: it detected the SOW-under-MSA relationship, fired the defer-to-MSA rule on both an early and a tail clause, caught the injection in the final line, and still reviewed the sections the injection tried to suppress.
