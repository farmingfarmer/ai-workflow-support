# Copilot Agent Request — Intake Form

**Data Science & AI Team.** Fill out what you can — "I don't know yet" is a fine answer; questions 3 and 4 matter most. You can also skip this form entirely and let our **Agent Architect** agent interview you instead; this is the paper version of the same conversation.

---

**1. About you**
- Name / Dept / Role:
- Best way to reach you:
- Who will *own* this agent after handoff (keep its instructions updated, collect user feedback)? Usually you or someone on your team — not the AI team.

**2. The process in one paragraph**
What do you (or your team) do today, by hand, that you want an agent to draft for you?

**3. The input** *(what the user gives the agent each time)*
- What is it? (a meeting transcript, a report, evaluation forms, notes, …)
- Where does it come from today, and in what format? (Teams transcript, Word doc, email, …)
- ☐ Check here if the input can involve patient data, student/learner records, or other regulated data. *(This doesn't disqualify the request — it changes how we test and where outputs may go. All testing uses synthetic data regardless.)*

**4. The output** *(the single most important question)*
- Do you have a template, example, or checklist of what good output looks like? ☐ Yes — **attach it** ☐ No — we'll help you draft one first (that's step one, before any agent)
- Are there required sections, checklists, or fixed value sets the output must follow exactly? List or attach them.

**5. Audiences**
- Who reads the output?
- Do different readers need different versions (e.g., a detailed internal one and a concise recipient-facing one)? ☐ No ☐ Yes — which parts must be word-for-word identical across versions?

**6. Review and sign-off**
- Who checks the draft before it's used or filed?
- Does anyone the output is *about* need to confirm it (a learner, an employee, a committee)? ☐ No ☐ Yes — who?

**7. Users and scale**
- Who will use the agent (names/roles, roughly how many people)?
- How often will it run? (per meeting, weekly, quarterly, …)
- Roughly how much time does the manual version take today?

**8. Timing**
- When do you want to start using it? Any hard deadline (accreditation cycle, program launch, …)?

---

**What happens next:** we review within a week. Most requests become a standard build: your template goes into agent instructions, you get a build guide plus a synthetic test file, and after a short feedback loop you own the agent — your colleagues can use it **without premium Copilot licenses** (validated in our tenant). Requests needing live document libraries, scheduled runs, system integration, or a custom interface are scoped separately as projects.
