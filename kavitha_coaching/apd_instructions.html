Coaching Session 1: Instructions for Coaches

IM Residency Coaching Program · Using the Session 1 Summarizer agent · October 2026

Before and during the meeting

  1. Schedule the coaching session as a private calendar meeting (from Outlook or the Teams calendar), never inside a Teams channel.
  2. If you have a premium Copilot license, turn on Facilitator when you create the meeting and paste the Session 1 agenda into the invite body. Facilitator paces the meeting and flags missed items. If you don't have a premium license, skip this step; the rest of the workflow still works.
  3. Turn on transcription at the start of the meeting (transcript only, not recording). This step is required: the transcript is what the agent works from.

After the meeting

  1. Download the transcript from the meeting recap (Meeting chat, then Recap, then Transcript).
  2. Access the coaching agent using this link: [Insert link]. Open it in the Microsoft 365 Copilot app or at m365.cloud.microsoft in a browser. You do not need a premium license for this step, but the agent will not appear inside Word.
  3. Upload the transcript from your coaching session and choose "Summarize this Session 1 transcript." The agent returns two documents: a detailed coach summary (with the session checklist and notes) and a concise learner summary.
  4. Review the coach summary first for accuracy. If the agent marked any checklist item "Not covered," plan to pick it up at the next session or by follow-up.
  5. Share the learner summary with your learner. They confirm it is a fair reflection of the conversation, or request corrections or removals. Make any requested changes before going further.
  6. Once the learner has confirmed, save the learner summary as a Word document. The agent suggests the filename; the pattern is LearnerLastname_Firstname_date (example: Smith_John_07.01.2026).
  7. Upload the confirmed learner summary to the shared OneDrive folder: Keck IM residency folder, KSOM Coaching program, then under your name, then 2026-2027, then Session 1s.

Confidentiality

  • Only the confirmed learner-facing summary goes to the shared folder.
  • The transcript, the coach summary, and any other coaching notes stay in your own OneDrive. The program does not have access to those files.
  • If something important needs to reach the program but is not in the learner summary, contact the program director directly.

Licenses, in one breath

Using the agent: no premium license needed (tested and confirmed). Any coach can run it from the Microsoft 365 Copilot app or m365.cloud.microsoft.
Using Facilitator: the person who organizes the meeting needs a premium Copilot license. Without one, simply turn on transcription and skip Facilitator; everything downstream works the same.

Feedback

The agent improves through versions, not through corrections in the chat (those vanish when the conversation ends). If the output misses something, words things poorly, or puts content in the wrong place, drop a note in the program's feedback thread. Fixes get folded into the next version for everyone.
